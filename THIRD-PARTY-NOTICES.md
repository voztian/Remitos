# Dependencias incluidas en GoRemitos v2.8

Las dependencias se alojan junto con la aplicación para evitar fallos de CDN y
cambios de contenido inesperados. Están en la raíz para que la actualización
desde la interfaz web de GitHub sea directa.

- Supabase JavaScript 2.110.6 — MIT — https://github.com/supabase/supabase-js
- Tabler Icons 3.44.0 — MIT — https://github.com/tabler/tabler-icons
- jsPDF 4.2.1 — MIT — https://github.com/parallax/jsPDF
- qrcodejs 1.0.0 — MIT — https://github.com/davidshimjs/qrcodejs

Servicio cargado en tiempo de ejecución:

- Cloudflare Turnstile — prevención de abuso en formularios de autenticación —
  https://developers.cloudflare.com/turnstile/

Cada archivo conserva su encabezado de licencia original cuando el paquete lo
incluye. Además, se reproducen a continuación los avisos requeridos para las
copias distribuidas.
