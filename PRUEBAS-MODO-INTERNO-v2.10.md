# Prueba interna v2.10

Usar únicamente nombres, domicilios, teléfonos, DNI, firmas, fotos y documentos ficticios.

1. Ingresar con un usuario **Administrador**.
2. Abrir **Usuarios** y activar **Modo de prueba interna**.
3. Ingresar con el usuario **Oficina**.
4. Crear un remito ficticio, adjuntar un PDF o una imagen de prueba y asignarlo al chofer.
5. Confirmar que la fila muestre la etiqueta **PRUEBA**.
6. Ingresar con el usuario **Chofer** e iniciar el viaje.
7. Revisar todos los ítems, usar receptor y DNI ficticios, dibujar una firma de prueba y cerrar.
8. Volver como administrador u oficina y comprobar detalle, trazabilidad, seguimiento y PDF.
9. Confirmar que el PDF diga **DOCUMENTO DE PRUEBA** y que no aparezcan botones de aviso por WhatsApp.
10. Con todas las pruebas cerradas o eliminadas, volver a **Usuarios** y desactivar el modo.

Si quedan pruebas pendientes, el sistema impedirá desactivar el modo para que el chofer pueda terminarlas.
